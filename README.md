# 김병태 · Byeongtae Kim

메가젠임플란트 융합IT실 **비즈니스앱팀** 팀장입니다.
사내 업무 시스템을 기획하고, 만들고, 운영합니다.

## 하는 일

- **기획** — 현업의 요구사항을 화면과 데이터 구조로 옮깁니다.
- **개발·운영** — 주문, 매출 조회, 문서 배포, 채용 같은 업무용 웹 서비스를 만들고 운영합니다.
- **표준화** — 팀 공통 아키텍처와 프로젝트 템플릿을 관리합니다.

## 일하는 방식

- **TDD** — 실패하는 테스트를 먼저 쓰고, 통과시킨 뒤에 다듬습니다.
- **Tidy First** — 구조 변경과 동작 변경을 한 커밋에 섞지 않습니다.
- **스키마는 마이그레이션으로만** — DB를 손으로 고치지 않습니다.
